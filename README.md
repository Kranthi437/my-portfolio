# Kranthi Kumar — Portfolio (3 design directions)

Open `index.html` to choose among three responsive portfolio styles:
- `executive.html` — premium dark / green accent
- `editorial.html` — refined warm light / serif headings
- `modern.html` — contemporary blue / product style

Each version includes the supplied portrait, downloadable resume, resume-grounded career and project details, and technology logo tiles. Skill logos are loaded from the Devicon CDN and therefore require an internet connection when viewing the site.

## Publish with Vercel
Upload this folder to a Git repository, import it in Vercel, and deploy as a static site. No build command is needed.

## Accuracy notes
The content reframes the resume into capability-led portfolio language without inventing client outcomes. The 20% defect reduction is included only because it appears in the resume. Cypress + JavaScript and Playwright + Python are explicitly listed in the skills section.
